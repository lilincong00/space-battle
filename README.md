# 🚀 星际大战 - Space Battle

一个炫酷的双人 HTML5 太空对战射击游戏！

12333333333333333333


## 🎮 游戏介绍

两架战机在星际空间中展开激烈对决，谁先击落对方谁获胜！

## 🕹️ 操作方式

### 🔴 烈焰战机 (玩家1 - 左侧)
- **W A S D** - 移动飞船
- **空格键** - 发射子弹



### 🔵 寒冰战机 (玩家2 - 右侧)
- **↑ ↓ ← →** - 移动飞船
- **回车键** - 发射子弹

## ✨ 游戏特性

- 🌟 动态星空背景
- 💥 炫酷爆炸特效
- 🔥 引擎粒子效果
- 💪 生命值系统
- 📊 比分记录
- 🎨 精美飞船设计
